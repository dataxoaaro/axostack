### Investigation

**Read-only. The deliverable is a cited answer, not a change.**

1. Classify the question. Empirical (observable by running something) → answer by running it, not by reading alone. Historical → `why`. Structural → `how`.
2. Fan out **how** and **why** as parallel subagents for anything cross-subsystem, per axo-mode's [Subagents](../SKILL.md#subagents) section.
3. Answer from the evidence. Every claim cites a file path, command output, or commit. Never fabricate a citation.
4. If the answer would change code, stop there. Report findings and the recommended next playbook. Don't apply a fix inside an investigation.

**Reply:** the answer first, then the evidence trail. Name what you did not check.
